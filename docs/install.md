# Installation

You will need Python and pip installed, as well as [Brownie](https://eth-brownie.readthedocs.io/en/latest/install.html) and either of [Anvil](https://book.getfoundry.sh/anvil/), [Hardhat](https://hardhat.org/getting-started/#installation), or [Ganache](https://github.com/trufflesuite/ganache) for the forked network functionality. Make sure you have [Brownie networks](https://eth-brownie.readthedocs.io/en/latest/network-management.html) configured correctly.

Then you can simply:

```bash
uv pip install brownie-safe --pre
```
